Diferenças Windows × Unix

🖴

Letras de unidade (C:\, D:\)

Cada volume tem sua própria raiz. No Unix, tudo é montado sob uma única raiz /.

🔀

Separador \ (barra invertida)

Windows usa \. Unix usa /. PowerShell aceita ambos modernamente.

👁️

Arquivos ocultos

No Windows, atributo "hidden" define ocultação. No Unix, prefixo ponto (.) é suficiente.

⚙️

AppData & Registro

Configs ficam em AppData (arquivo) e no Registro do Windows (base de dados interna).

🔤

Extensões obrigatórias

Windows usa extensão para identificar tipo (.exe, .dll, .docx). Unix não depende delas.
